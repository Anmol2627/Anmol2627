## Selected Work

<br/>

<table>
<tr>

<td valign="top" width="50%">

### 🏦 BharatScore AI
**Credit for people the system forgot**

190M+ Indians have no formal credit history — not because they're unreliable, but because the infrastructure never reached them. BharatScore uses UPI transaction patterns, utility bills, and behavioral signals to build explainable credit profiles with RBI compliance in mind. Built to go from hackathon to something real.

`XGBoost` `Random Forest` `SHAP` `FastAPI` `Python`

**[→ View Repository](https://github.com/Anmol2627)**

</td>

<td valign="top" width="50%">

### 🎬 YouTube Semantic Search
**An AI that watches videos so you don't have to**

Give it a natural language question; it returns the precise moment in any YouTube video — not a search result, an actual timestamp. Built on Whisper transcription, sentence-level chunking, and FAISS vector search. The interface is just a question box and a deep-linked timestamp.

`Whisper` `FAISS` `Sentence-BERT` `FastAPI` `Python`

**[→ View Repository](https://github.com/Anmol2627)**

</td>

</tr>

### 🛡️ SafeCircle
**Your trusted circle, always one tap away**

A personal safety platform built around the idea that emergencies shouldn't require more than one action. Real-time location sharing, SOS alerts, and a secure trusted-contact network — designed for the seconds that count.

`Mobile` `Cloud Backend` `Real-time Location`

**[→ View Repository](https://github.com/Anmol2627)**

</td>

### ⚽ Nexus
**The missing layer in sports talent discovery**

A platform bridging aspiring athletes with coaches, academies, and tournaments. For the players who are good enough to be noticed — but haven't had a stage yet. Profiles, discovery, tournament hosting, and scout access in one ecosystem.

`Web Platform` `Node.js` `PostgreSQL`
