      <h3>🎯 AI-Powered YouTube Semantic Search Engine</h3>
      <p>Building an AI system that finds <strong>the exact moment in any YouTube video</strong> matching a user's natural language query — by transcribing videos and matching them semantically using vector embeddings.</p>
      <p>
        <img src="https://img.shields.io/badge/Status-In_Progress-6366f1?style=flat-square&logo=statuspage&logoColor=white"/>
        <img src="https://img.shields.io/badge/Stack-Python%20%7C%20Whisper%20%7C%20FAISS%20%7C%20LangChain-0f172a?style=flat-square"/>
      </p>
      <details>
        <summary>📐 Architecture Overview</summary>
        <br/>
        <ul>
          <li>🎙️ <strong>Transcription</strong> — OpenAI Whisper extracts timestamped transcripts</li>
          <li>🧠 <strong>Chunking & Embedding</strong> — Sentence-level chunking + OpenAI/HuggingFace embeddings</li>
          <li>🗄️ <strong>Vector Store</strong> — FAISS for fast similarity retrieval</li>
          <li>🔍 <strong>Semantic Matching</strong> — Cosine similarity over dense vectors</li>
          <li>⚡ <strong>Output</strong> — Deep-linked YouTube timestamps for exact moments</li>
        </ul>
